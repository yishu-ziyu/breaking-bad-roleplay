# ABQ Roleplay Lab — Hermes Project Context

This repository is the Breaking Bad roleplay project: a React/Vite frontend plus FastAPI backend for character chat, crew debate, and story/SSE roleplay experiences.

## Product Direction

Historical roadmaps, `.ship` loops, and “next round” queues are **not specs**. See `docs/PLANNING.md`.

- Treat the product as an interactive AI roleplay / story engine, not just a basic chatbot.
- Preserve immersion while avoiding real-world operational criminal instructions.

## Deployment Direction

Live ops (binding): `docs/OPS_RUNBOOK.md`. Canonical URL: `https://bb.yishuziyu.cn`.

- Prefer the full FastAPI runtime path for production-facing work.
- The production Docker image should build the frontend inside Docker and serve `dist/` from FastAPI.
- Database schema is managed by Alembic. Do not reintroduce startup `Base.metadata.create_all()` for production.
- Never commit real API keys, Render/Supabase secrets, or database connection strings.
- Older Render-first notes in this file are historical, not the current deploy obligation.

## Verification

Before declaring deployment or code changes complete, run the relevant checks:

- Frontend change: `npm run build` and `npm test` from repo root.
- Backend change: `cd backend && env -u PYTHONPATH -u VIRTUAL_ENV uv run pytest`.
- Deployment change: follow `docs/OPS_RUNBOOK.md`; `GET /api/health` and a browser smoke test on `https://bb.yishuziyu.cn` when possible.
- Visual/UI change: inspect the page in a browser screenshot, not only code/build output.

## Important Areas

- Frontend app shell: `src/App.tsx`, `src/App.css`.
- Scene backgrounds: `public/backgrounds/`, `src/lib/sceneBackgrounds.ts`.
- Character profiles/assets: `src/roleProfiles.ts`, `src/roleAssets.ts`, `materials/breaking-bad/`.
- Story stream hook: `src/hooks/useStoryStream.ts`.
- FastAPI routes: `backend/api/routes.py`.
- Agent runtime: `backend/agents/director.py`, `backend/agents/characters/`, `backend/agents/provider.py`, `backend/agents/memory.py`.
- DB/Alembic: `backend/db/`, `backend/alembic/`.

## Communication Preference

- For deployment and handoff work, explain slowly and step-by-step.
- Keep summaries concise, but include what was changed, what was verified, and what remains risky.
- If a cloud deployment fails, inspect real logs before proposing fixes.
