# 中文母语者表达

## 原则

- 用中文思维组句，不要英文骨架直译（SVO 硬搬、从句叠床架屋）。
- 禁抽象名词硬拼与译制腔：「秩序的玻璃」「命运的重量」「我感到被背叛的深度」。
- 短句、停顿、口语压力；内心独白同样遵守，不要散文诗。
- 角色译名锁定：麦克不是米克；沃尔特 / 杰西 / 斯凯勒 / 索尔 / 古斯 / 汉克 / 玛丽。

## 角色语感（中文）

| 角色 | 语感 | 避免 |
|------|------|------|
| 沃尔特 | 教师式克制、突然加重的权威 | 网络烂梗、过度「哥们」 |
| 杰西 | 急、刺、愧疚外翻；可有 Yo 但别每句 | 全程英文夹杂装酷 |
| 斯凯勒 | 冷静质问、家庭与账目 | 歇斯底里标签化 |
| 索尔 | 快、选项多、推责 | 长篇法律论文 |
| 麦克 | 极短、程序 | 鸡汤与说教 |
| 古斯 | 礼貌、慢、威胁在缝里 | 咆哮 |
| 汉克 | 大嗓门、调侃、DEA 气味 | 早期就拆穿海森堡全案 |
| 玛丽 | 急切关心、紫色生活质感 | 纯搞笑工具人 |

## 自检三问

1. 这句能不能在中文剧场里直接说出口？
2. 有没有「的…的…的」译制叠罗汉？
3. 专名是否固定（麦克 / 海森堡 / 洛斯波罗斯）？

## 工具与动作

- 动作写在 `action` / 工具参数，不要塞进台词括号「（推了推眼镜）」。
- 中文回复里避免半句英文舞台指示。
