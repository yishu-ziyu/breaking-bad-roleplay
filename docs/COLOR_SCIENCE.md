# 色彩科学（本项目必须遵守）

进门第一眼要像这部剧的静帧，不要像 iOS 设置页。结构可以借 Apple（字号 12/13/14/24、胶囊、8/16），**颜色不能借 Apple 的冷灰**。

## 从谁来

| 人 | 角色 | 对我们有用的一句 |
|---|---|---|
| Vince Gilligan | 创剧 | 西部片。人要小，地平线要大。新墨西哥的天是角色。 |
| Michael Slovis | BB 摄影指导 S2–S5 | 不跟沙漠对着干。烟草滤镜把褐、金、黄推出来，像茶渍。暗画面里要有一个热点把眼睛拽过去。 |
| Tom Sartori | FotoKem 调色 | 只细修，不把片子洗成别的地方。夜里加钠灯黄。 |
| Mark Freeborn / 美术 | BB 美术 | 地点和人同等重要。室内偏暗，好让光说话。 |
| Ted Brady | BCS 调色 | 吉利根喜欢霍珀：暗里颜色仍然亮。索尔办公室深橙；美甲店可以俗、可以饱和。 |
| Jennifer Bryan | 服装 | BB：颜色跟角色弧线走。BCS：颜色给身份分类（合法侧冷、沙漠侧热）。 |

滤镜工具：Slovis 用 Schneider True-Pol 压天空、coral/tobacco/straw 暖地面。我们没有镜头，用 **oklch 暖色相（约 60–85）** 代替冷灰。

## 调色板（世界）

| 名 | 用途 | 约值 |
|---|---|---|
| bone | 字、可点的热物 | `oklch(0.93 0.025 85)` |
| dust | 次级字 | `oklch(0.74 0.035 75)` |
| umber | 世界底、外壳 | `oklch(0.20 0.038 62)` |
| plate | 壳上的浅一层 | `oklch(0.26 0.042 68)` |
| Heisenberg 绿 | 唯一冷强调，少用 | 现有 `--dn-accent` |
| 钠灯黄 | 夜戏、额度、警告 | 现有 `--dn-amber`，不要当主按钮 |

禁止：`#292929 / #5D5D5D / #9E9E9E` 当**世界色**。那是库比蒂诺的灯。照片上的字用骨白，不要用冷灰。

## 两条硬规则

1. **世界 ≠ 选择。** 底盘、天空、外壳走烟草/褐金。让人挑的东西必须是热点：骨白或浅茶渍，和底分开。不要褐上叠褐当选项。
2. **先画面后界面。** 宽、空、静帧。卡片是沙漠里的一张纸，不是贴上去的设置面板。

## 按用户路径用

1. **进门静帧**（沙漠照片）：世界色。人小、天大。
2. **索尔打招呼 / 选玩法**：外壳 umber，**选项 bone**。选完再进各自的色温。
3. **剧情**：继续黄尘、钠灯、绿只作强调。
4. **单聊**：一对一，仍是骨/褐，不要掉回浅色聊天壳。
5. **群聊**：可以更满、更挤，仍不要 iOS 白。

索尔的办公室以后可以偏深橙、更俗；那是他的房间，不是进门第一屏。

落地实现目前在 `src/styles/temp-apple-skin.css` 的 `.cold-open { --bb-bone; --bb-dust; --bb-umber; --bb-plate }`。改世界色改这里，不要另起一套冷灰。
