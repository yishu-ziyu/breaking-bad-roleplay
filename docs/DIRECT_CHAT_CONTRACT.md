# Direct 单聊 — 验收契约（2026-09-15）

## 变更（用户能看到什么）

- 打开单聊：角色像发消息一样先开口（他此刻在干什么 + 你们是什么关系 + 一个钩子）；开场白按你选的关系挑（`OPENERS_BY_RELATION`），不会和关系对不上。
- 八个人说话行为不同：每个角色设定里有 CONVERSATION BEHAVIOR（说多长、答不答、解不解释、被逼时怎样）；单聊长度跟着它走，不再有统一的句数。
- 多次回访：开场不机械重复；有未完线时优先接线。
- 长聊 / 隔天：角色能自然用到五类关系记忆，不念档案。
- 说话像人：短句、有脾气、不像客服/助手。
- 关系：进门选一次粗锚点；开聊后不当每轮菜单。

## 不算数

- 关系数值条、可见「今日目标」、检定/胜负。
- 把 Story 进度灌进单聊。
- 大段第三人称定场或开场选项菜单。
- 开场自我指涉「这场谈话」、预告语气菜单、自我辩解式免责（「我不是来……」）。

## 谁验收

- 自动：开场库 / 记忆五类 / Direct craft 注入相关单测；`backend/tests/test_character_voices.py`。
- 真模型：`cd backend && uv run python -m eval.character_resistance --label <名字>`（八人 × 5 条诱导出戏 + 裁判 3 票取多数；会消耗额度）。2026-10-01 基线 26/40 → 34/40，见 `docs/research/`。
- 主观：产品负责人打开 Direct，十分钟仍想回访。
