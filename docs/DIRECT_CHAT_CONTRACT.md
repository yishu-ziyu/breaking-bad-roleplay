# Direct 单聊 — 验收契约（2026-09-15）

## 变更（用户能看到什么）

- 打开单聊：角色已在生活里先开口（M 档：生活细节 + 钩子）。
- 多次回访：开场不机械重复；有未完线时优先接线。
- 长聊 / 隔天：角色能自然用到五类关系记忆，不念档案。
- 说话像人：短句、有脾气、不像客服/助手。
- 关系：进门选一次粗锚点；开聊后不当每轮菜单。

## 不算数

- 关系数值条、可见「今日目标」、检定/胜负。
- 把 Story 进度灌进单聊。
- 大段第三人称定场或开场选项菜单。
- 开场自我指涉「这场谈话」、预告语气菜单、自我辩解式免责（「我不是来……」）。
