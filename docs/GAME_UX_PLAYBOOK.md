> 本文档搬运行业内公认的游戏 UX / 引导规范，并逐条对照本项目（ABQ Roleplay Lab）。
> 每条规范标注来源；「对照」列给出本项目现状。新功能开发时按本清单过一遍。
> 最近对照日期：2026-08-27（知识分层 FTUE 重构后）

## 设计原则（评测挑战后确立）

**FTUE 的第一前提：不假定玩家看过剧。** 一切引导按玩家的知识分层：
进场只问一句话（"你看过《绝命毒师》吗？"），之后所有文案按答案分两轨——
`fresh`（零前置：每个名字/赌注随剧情 inline 交代）与 `fan`（紧凑、典故化）。
知识分层贯穿三层：简报屏、危机文本、喂给 LLM 的故事种子。
**引导的形态是"少读一个字也好"，不是"多讲一屏"**：把 3 屏说明书压成 1 次点击。

## 0. 概念正名 [Q4UX]

三个词不是同义词，是**包含关系**：

```
Onboarding（留存全周期：首次进游戏 → D7）
  └── FTUE（第一次打开游戏的那段体验，几分钟级，最致命）
        └── Tutorial（教机制的交互教学，FTUE 的一种实现手段）
```

- **FTUE** 管第一印象：玩家是否在 30–60 秒内理解"这是什么、我要干什么、为什么好玩"。
- **Tutorial** 管机制：让玩家**动手做一遍**，不是读说明书。
- **Onboarding** 管回访：第二次打开时，老玩家要不要重看引导？（答案：不要。）

## 1. FTUE 规范 [OW]

| # | 规范 | 本项目对照 | 状态 |
|---|---|---|---|
| F1 | 欢迎屏传达核心价值主张（这是什么/凭什么好玩），制造第一眼 WOW | 无任何欢迎屏，落地即冷开场。价值主张（AI 演绎、你主导剧情）全靠玩家自己悟 | ❌→已补 `OnboardingBrief` |
| F2 | 欢迎屏必须有清晰可见的**跳过/关闭**按钮 | —（新组件默认带「直接开演」跳过） | ✅（新） |
| F3 | 尽快开始（time-to-fun）：保持简短，让玩家快速开始玩 | 冷开场即玩法（三选一就是第一次游玩），天然满足 | ✅ |
| F4 | 空状态带简短说明（empty states with a short explanation of what to expect） | 续玩会话失效时有 resumeToast 说明 | ✅ |
| F5 | 引导必须无缝、非打断（Users should not feel interrupted） | 新引导浮层一次性、可跳过、不重复出现 | ✅（新） |
| F6 | 不要过度解释（Don't overwhelm users） | 教学拆成「开场 3 屏」+「实战 1 提示」，不堆一个长教程 | ✅（新） |

## 4. 尼尔森十大启发式 × 游戏 [NN/g]

| # | 启发式 | 游戏演绎 | 本项目对照 | 状态 |
|---|---|---|---|---|
| H1 | 系统状态可见性 | 血条式的即时反馈：玩家操作后系统是否立刻回应 | SSE 逐拍流式渲染；行动提交有「局面展开中…」态；进入故事有 diegetic 过场 | ✅ |
| H2 | 贴近真实世界 | 游戏语言用玩家熟悉的隐喻 | 剧内语言（氨水/车灯/时间码 OSD）已对齐 | ✅ |
| H3 | 用户控制与自由 | 撤销/退出/不强制 | 可返回选择、可自由输入、语言可切换 | ✅ |
| H4 | 一致性与标准 | 同一操作全游戏同一反馈 | chips/自由输入行为一致；但底部决策条与冷开场按钮风格待统一复查 | ⚠️ |
| H5 | 错误预防 | 危险操作确认、非法输入防呆 | 双击防抖（starting 阻断）、连接预检 gate | ✅ |
| H6 | 识别而非回忆 | 不逼玩家记住规则 | 每次暂停 chips 重新提示可选行动 | ✅ |
| H7 | 灵活与效率 | 新手有引导、高手有捷径 | 新手：chips；高手：自由输入 + 继续 | ✅ |
| H8 | 美学与极简 | 无关信息不堆砌 | 冷开场已清理（眉标删除） | ✅ |
| H9 | 错误识别与恢复 | 报错说人话、给出路 | 连接失败 banner + resumeToast（404 说明 + 处理） | ✅ |
| H10 | 帮助与文档 | 随时可查的规则说明 | **完全缺失**：无任何玩法说明入口 | ❌→部分（引导 + 待回看入口） |

## 5. 参与度三支柱 [Hodent]

| # | 支柱 | 含义 | 本项目对照 | 状态 |
|---|---|---|---|---|
| E1 | 心流 Flow | 难度与技能匹配、无打断焦虑 | 节拍推进节奏由 AI 控制，玩家始终有下一步可做 | ✅ |
| E2 | 动机 Motivation | 自主感/胜任感/关联感（SDT） | 三选一 + 自由输入=自主感；剧情推进=胜任感；角色关系=关联感 | ✅ |
| E3 | 情绪 Emotion | 视听语言服务情绪目标 | 冷开场情绪（紧张夜）已由色彩/字体/时间码体系承载 | ✅ |

## 6. 叙事选择设计 [Agency]

| # | 规范 | 本项目对照 | 状态 |
|---|---|---|---|
| N1 | 选择要有上下文（context for choices） | 三个行动选项全部长在危机文本上（氨水/车灯/杰西） | ✅ |
| N2 | 分支保持最小（keep branching minimal），用微决策铺量 | 线性主轴 + beat 级微决策（chips），不搞状态爆炸 | ✅ |
| N3 | 每个决定独特、有分量（house style：no fake choices） | chips 由选项+角色派生（DramaDecisionBar），非通用 filler | ✅ |
| N4 | 玩家能动性分层：显式选择 / 微决策 / 自由行动都要有 | 显式（冷开场）、微决策（chips）、自由（free input）三层齐备 | ✅ |
| N5 | 选择后果可感知（chosen echo / world delta） | 「你已选：」回显 + worldDelta 文本注入 | ✅ |
