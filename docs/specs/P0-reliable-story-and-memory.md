本轮基线：`55df802`。用户已授权直接实现；不更换首页、不部署、不调用其他模型。

## 验收契约

### A. 剧情行动

- Given 已有剧情、大纲与世界状态，When 玩家执行普通行动，Then 不以 `redirect` 清空大纲或归零章节。
- Given 同一行动编号，When 重试或断线重连，Then 不重复推进世界、不重复交接物品，返回已保存的结果。
- Given 已损坏物品、已确定的持有人或不在场的人，When 提交与条件冲突的行动，Then 规则拒绝；模型文字不能修改这些事实。
- Given 最终台词未通过校验或数据库提交失败，When 生成结束，Then 不向玩家发布候选，也不让候选污染后续角色知识。
- Given 已提交一拍，When 刷新或恢复，Then 能取回同一份公开事件，而不是重新编一份。
- 第一版覆盖有限的动作与场面；不把任意自然语言宣称当成已经发生的事实。未知动作明确拒绝或要求澄清。

### B. 角色与记忆

- Given Direct 的轻量 dossier，When 构造模型输入，Then 保留同源角色核心策略、身份与知识边界；不依靠文本前缀猜测权限。
- Given 中文身份、秘密、承诺、态度或约定，When 提取并再次对话，Then 五类记忆均有机会进入模型上下文，不能只使用 open_thread。
- Given 很多普通未完话题，When 记忆达到上限，Then 不挤掉所有身份、秘密和约定；传输长度不超过 API 限制。
- 客户端记忆是有来源的说法，不是系统指令，也不能自行授予可信的世界效果或角色权限。
- 单聊保持短句，无可见信任条；独立 Direct 不自动继承另一局 Story 的身份与剧情。

## 不包括

Crew 抢话、语音打断、向量数据库、真实支付、换运行框架、七角色全量真人质量评估是后续工作。
