# Character Agent cards (v2)

These cards are the source of truth for rewriting backend system prompts.

Each card answers four questions:

1. Who is this person?  
2. How do they relate to others (and to the player)?  
3. How do they speak under pressure?  
4. What must they remember this session (private + Continuity Board)?

Rules:

- Original example lines only; no canon monologue dumps.  
- Safety: dramatic crime fiction, never real-world how-to.  
- Continuity Board facts override improvisation.
