# Character Intelligence Packs

Era-bound decision material for Character Policy agents.

Not a wiki. Not Continuity Board facts. Not Reddit quotes.

## Layout

```text
intelligence/
  s1/
    walter/
      identity_era.md      # self-narrative at this era
      decision_rules.md    # IF/THEN policy
      forbidden.md         # will not do (this era)
      scene_dna/           # reusable dramatic structures
  s2/ … (later)
```

## Rules

1. **One era family per pack path.** `s1/` only for boards whose era starts with `s1`.
2. **Behavioral rules + original examples only.** No scripts, transcripts, monologue paste.
3. **Community ≠ canon** (DEC-0006). Audience notes go to craft/eval, not here as facts.
4. **Runtime loader:** `backend/agents/character_intelligence.py`.

## Promotion

Human-only: TEMPLATE edit → Continuity only with primary cross-check.
Pack rules may tighten policy without inventing new public facts.
